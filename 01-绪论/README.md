## 复杂度速查

| 量级 | 例子 |
|---|---|
| `O(1)` | 数组按下标取值 |
| `O(log n)` | 二分查找 |
| `O(n)` | 遍历一遍 |
| `O(n log n)` | 快排、归并 |
| `O(n²)` | 冒泡、插入排序 |
| `O(2ⁿ)` | 递归求斐波那契（朴素） |
