## 核心知识点

### 顺序表 vs 链表

| | 顺序表 | 单链表 |
|---|---|---|
| 内存 | 连续 | 分散 |
| 随机访问 | ✅ `O(1)` | ❌ `O(n)` |
| 插入/删除 | `O(n)`（要搬元素） | `O(1)`（改指针，但找位置要 `O(n)`） |
| 额外空间 | 可能浪费（预分配） | 每个节点多一个指针 |
| 缓存友好 | ✅ 连续内存 | ❌ 跳来跳去 |

**一句话：查得多用顺序表，插删多用链表。**

### 顺序表的三个要素

```c
typedef struct {
    int *data;      /* 存数据的连续内存 */
    int  length;    /* 当前元素个数 */
    int  capacity;  /* 容量 */
} SqList;
```

**教材里常用 `elem` + `length` + `listsize`，本质一样。**

### 顺序表插入的关键：从后往前搬

```c
for (int i = length; i > pos; i--)
    data[i] = data[i - 1];      /* 从后往前，不会覆盖 */
data[pos] = x;
length++;
```

**如果从前往后搬（`i = pos; i < length; i++`），`data[pos]` 会被后面覆盖——数据就毁了。**

### 顺序表删除的关键：从前往后搬

```c
for (int i = pos; i < length - 1; i++)
    data[i] = data[i + 1];
length--;
```

### 单链表的头插 vs 尾插

```c
/* 头插：O(1)，但顺序是反的 */
p->next = head;
head = p;

/* 尾插：O(n)，要走到最后 */
Node *cur = head;
while (cur->next) cur = cur->next;
cur->next = p;
```

**想 O(1) 尾插，就多存一个尾指针 `tail`。**
