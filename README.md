跟着 **王卓《数据结构与算法基础》（青岛大学，B 站 BV1nJ411V7bd）** 学的代码记录。

教材对应：严蔚敏《数据结构（C 语言版）》，8 章。

## 为什么用 C 写

C 里能看见指针、内存布局、`malloc` 的开销——这些是理解数据结构的核心。
Java 的 `ArrayList`、`HashMap` 把实现藏起来了，学的是 API，不是数据结构。

## 代码规范

- `gcc -std=c11 -Wall -Wextra` 编译，**零警告**
- 每个 `malloc` 都要有对应的 `free`
- 接口函数返回 `int` 表示成功/失败
- 注释用中文，打印用英文（避免控制台编码问题）

## 编译与测试

```bash
gcc -std=c11 -Wall -Wextra 2.2-顺序表的实现.c -o seqlist
./seqlist
```

## 学了什么（按章记录）

### 第 1 章 绪论
- 数据、数据元素、数据项、数据对象
- 逻辑结构：集合、线性、树、图
- 存储结构：顺序存储、链式存储
- 抽象数据类型 ADT
- 时间复杂度：`O(1)` / `O(log n)` / `O(n)` / `O(n log n)` / `O(n²)` / `O(2ⁿ)`
- 空间复杂度

### 第 2 章 线性表
- 顺序表：连续内存、按下标随机访问、插入删除要搬元素
- 单链表：不连续、靠指针串起来、头插 O(1)
- 循环链表、双向链表
- 应用：两个有序表合并
