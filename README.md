# 数据结构（C 语言实现）

大一上学期开始学数据结构，每个结构都用 C 从零实现一遍，不调库。

## 为什么用 C 而不是 Java/Python

C 里能看见指针、内存布局、`malloc` 的开销——这些是理解数据结构的核心。
Java 的 `ArrayList`、`HashMap` 把实现藏起来了，学的是 API，不是数据结构。

## 路线图

| 模块 | 内容 | 关键操作 | 复杂度 |
|---|---|---|---|
| 01-sequential-list | 顺序表（动态数组） | 增删改查、扩容 | 查 O(1)，插入/删除 O(n) |
| 02-linked-list | 单链表、双链表 | 头插、尾插、删除、反转 | 查 O(n)，头插/删 O(1) |
| 03-stack-queue | 栈、队列、循环队列 | push/pop、enqueue/dequeue | 全部 O(1) |
| 04-string | 串、KMP | 匹配 | 朴素 O(nm)，KMP O(n+m) |
| 05-tree | 二叉树、二叉搜索树、遍历 | 前中后序、层序、插入删除 | 平均 O(log n) |
| 06-heap | 堆、优先队列 | 上浮、下沉、建堆 | O(log n)，建堆 O(n) |
| 07-graph | 图的存储、遍历、最短路 | 邻接表、DFS/BFS、Dijkstra | 视算法 |
| 08-sort | 排序算法 | 快排、归并、堆排 | 平均 O(n log n) |
| 09-hash | 哈希表 | 拉链法、开放寻址 | 平均 O(1) |

## 每个模块的约定

每个文件夹里放：

```
NN-模块名/
├── README.md        这个结构的思路、复杂度、踩坑记录
├── xxx.h            接口声明
├── xxx.c            实现
└── test.c           测试代码
```

**代码规范：**

- 用 `-std=c11 -Wall -Wextra` 编译，**零警告**
- 所有 `malloc` 都要有对应的 `free`
- 接口函数返回 `int` 表示成功/失败，不用 `void`
- 打印用英文，注释用中文

## 编译与测试

```bash
gcc -std=c11 -Wall -Wextra test.c xxx.c -o test
./test
```

## 规划说明

顺序：**线性结构 → 树 → 图 → 排序 → 查找**

理由：

- 顺序表和链表是后面一切的基础（栈、队列都是它们的特化）
- 树要用到递归，所以放在链表之后
- 图要用到队列（BFS）和栈（DFS），所以放在栈队列之后
- 排序里的堆排要用到堆，所以堆排在前面
